Python Programming Review
==========================

이 저장소는 **파이썬 프로그래밍 복습용 코드**와 **간단한 미니 프로젝트(과제 형태 연습)**를 모아둔 폴더입니다.  
수업에서 다룬 기본 문법부터 파일 입출력, 클래스, 자료구조까지 단계적으로 복습할 수 있도록 구성되어 있습니다.

## 폴더 구조

- **basics/**
  - 수업 중 실습 코드, 간단한 퀴즈/연습 코드 모음
  - 주요 파일:
    - `02.py` : 자료형, 논리형, 산술 연산자, `input`/`print` 등 **기본 입출력 및 연산**
    - `03.py` : `%` 포매팅, `str.format`, f-string, 슬라이싱/인덱싱 등 **문자열 포매팅과 문자열 다루기**
    - `04.py` : 튜플/리스트의 **기본 연산, 인덱싱, 슬라이싱**
    - `05.py` : `for`/`while`, `range`, 리스트 내포, 점수 평균·최대·최소 등 **제어문과 반복문 활용**
    - `06.py` : 딕셔너리, 중첩 딕셔너리/리스트, 중첩 반복문 등 **딕셔너리와 중첩 자료구조**
    - `07.py` : 함수 정의, 매개변수 종류, 가변 매개변수, 지역/전역 변수 등 **함수 기초와 심화**
    - `09.py` : `Point`, `Rectangle`, `Student` 등 클래스를 정의하고 사용하는 **클래스 연습 및 매직 메소드(`__str__`) 예제**
    - `10.py` : `os`와 파일 입출력을 사용해서 학번/이름 정보를 `data/test01.txt`에 저장/읽기
    - `additional_code.py` : 리스트/딕셔너리 평균, 값 삭제, 중복 개수 세기 등 **추가 알고리즘 연습 코드**
    - `intergrated.py` : 문자열, 리스트, 튜플, 포맷팅 등 여러 주제를 한 파일에 모아둔 **종합 복습 코드**
    - `quiz(new).py` : 리스트/딕셔너리 관련 **문제(21~24번 등)를 함수로 구현한 연습**
    - `likeAssignmentOrNoAssignment.py` : `Score` 클래스로 중간/기말/출석/과제 점수를 관리하고 총점·학점을 계산하는 **간이 성적 관리 클래스**
  - `data/`
    - `test01.txt` : `10.py`에서 사용하는 예제 데이터 파일

- **test1/**
  - `book.py`, `base.py`, `books.csv`, `main.py`로 구성된 **간단한 도서 정보 출력 프로그램**
  - `books.csv`를 읽어서 `Book` 객체 리스트를 만들고, 도서 정보를 출력하는 연습 코드

- **test2/**
  - 입실/퇴실 시간을 기록하고 **머문 시간(초 단위)**을 계산하는 프로그램
  - `student.txt`를 읽어서 `Record` 객체를 만들고, 새 기록을 입력받아 파일에 append 하는 구조

- **test3/**
  - 학생 이름과 과목별 점수를 파일로 저장하고, 다시 읽어와 **평균 점수**를 계산/출력하는 프로그램
  - `Student` 클래스를 사용하여 `to_string`, `average` 등을 구현

- **test4/**
  - `Book`, `Library` 클래스를 사용한 **도서 대여 시스템**
  - 기능:
    - 책 목록 보기
    - 책 대여 (7일 후 반납 예정일 계산)
    - 책 반납
    - 종료 시 전체 책 정보 파일로 저장

- **test5/**
  - `Animal`, `VaccinRecord` 클래스를 이용한 **동물 예방접종 기록 시스템 설계 연습**
  - `classes.py`에는 메소드들이 뼈대만 정의되어 있고, 직접 구현해보는 형태
  - `main.py`는 동물 ID를 입력받고 `records` 딕셔너리를 구성하는 부분까지 작성되어 있음

## 실행 방법

- **기본 실습 코드(basics)**  
  - 개별 파일을 직접 실행하면 됩니다.
  - 예시:
    - 터미널에서:
      - `python basics/02.py`
      - `python basics/05.py`

- **미니 프로젝트(test1 ~ test5)**  
  - 각 폴더로 이동한 뒤 `main.py`를 실행하세요.
  - 예시:
    - `cd test1` → `python main.py`
    - `cd test4` → `python main.py`

## 활용 팁

- 기본 문법이 헷갈릴 때는 **`basics/` 폴더**에서 해당 주제의 파일만 골라 빠르게 복습할 수 있습니다.
- 파일 입출력, 클래스, 자료구조를 응용한 연습이 필요할 때는 **`test1`~`test5`**를 과제처럼 다시 구현해보면 좋습니다.
