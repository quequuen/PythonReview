🔹 문제 2. 성적 관리 시스템 (클래스 + 딕셔너리 + 파일)

- 목표:
학생과 과목 성적을 저장하고 평균을 계산하는 프로그램을 만든다.

- 조건:

Student 클래스 생성

속성: name, scores (dict)

메서드

average()

to_string() → 파일에 저장할 문자열

입력 예시

이름: 홍길동
과목명: 수학
점수: 90

과목명: 영어
점수: 80
-> 종료하려면 엔터


파일 저장 형식:

홍길동|수학:90,영어:80,과학:75


프로그램 실행 시 파일을 읽어

학생마다 평균 점수 출력

출력 예시:

홍길동 평균: 81.6
김영희 평균: 91.3


연습 포인트
✅ 클래스 안에서 딕셔너리 관리
✅ 파일에 저장→ 다시 복구
✅ 평균 계산
