🔹 문제 3. 도서 대여 시스템 (클래스 + 파일 입출력)
🎯 목표

도서 정보를 파일로 저장하고, 프로그램 실행 시 파일에서 다시 불러와서
사용자가 책을 대여하거나 반납할 수 있는 간단한 도서 관리 시스템을 만든다.

📌 1. 저장 파일 형식과 규칙
🔸 데이터 파일: books.txt

각 줄은 한 권의 책을 나타내고 다음 형식으로 저장된다:

제목|저자|is_rented|반납예정일


is_rented → 책이 대여 중인지 여부 (True 또는 False)

반납예정일

대여 중이면 날짜(문자열) 저장
예: 2025-04-12 12:12:12

대여 가능이면 빈 문자열 ""

📌 예시
해리포터|J.K.롤링|False|
데미안|헤르만 헤세|True|2025-04-12 12:12:12

📌 2. 클래스 설계
✅ class Book
속성	설명
title	책 제목
author	저자
is_rented	현재 대여 여부 (True/False)
due_date	반납 예정일 (datetime 또는 None)
메서드

to_string()
Book 객체를 파일에 저장 가능한 문자열로 변환
형식: "제목|저자|is_rented|반납예정일"

✅ class Library
속성	설명
books	Book 객체 리스트
메서드 상세 요구사항
1) load_books()

books.txt 파일을 읽어서 Book 객체로 변환하여 self.books에 저장

파일이 없으면 빈 리스트 유지

날짜 문자열이 비어 있으면 due_date = None

2) save_books()

프로그램 종료 직전에 호출

현재 self.books 내용을 books.txt에 모두 저장

Book 객체의 to_string() 사용

3) print_books()

다음 형식으로 책 목록을 출력:

[1] 해리포터 - 대여 가능
[2] 데미안 - 대여 중 (반납예정: 2025-04-12 12:12:12)


규칙:

대여 가능: is_rented == False

대여 중: is_rented == True

대여 중일 때만 반납예정일 표시

4) rent_book(title)

제목으로 책 검색

없으면 → "책을 찾을 수 없습니다."

이미 대여 중이면 → "이미 대여 중입니다."

대여 가능하면:

is_rented = True

due_date = 현재시간 + 7일

"대여 완료!" 출력

5) return_book(title)

제목으로 책 검색

없으면 → "책을 찾을 수 없습니다."

대여 중이 아니면 → "이 책은 대여 상태가 아닙니다."

대여 중이라면:

is_rented = False

due_date = None

"반납 완료!" 출력

📌 3. 사용자 인터페이스 (반드시 포함해야 함)

프로그램은 다음 메뉴를 반복 출력해야 한다:

====== 도서 대여 시스템 ======
1. 책 목록 보기
2. 책 대여
3. 책 반납
4. 종료
메뉴 선택: 

메뉴 동작
번호	동작
1	library.print_books() 호출
2	제목 입력받아 library.rent_book(title) 실행
3	제목 입력받아 library.return_book(title) 실행
4	library.save_books() 호출 후 프로그램 종료
📌 4. 출력 예시
도서 목록
[1] 해리포터 - 대여 가능
[2] 데미안 - 대여 중 (반납예정: 2025-04-12 12:12:12)

대여
대여할 책 제목 입력: 해리포터
대여 완료!

반납
반납할 책 제목 입력: 데미안
반납 완료!
